Integration & Setup

Developer & API Documentation

Build on top of SeeForMe. Integrate the REST endpoints into mobile apps or stream live video over WebSockets.

1. Quickstart & Local Installation

Set up and run SeeForMe locally using Python 3.13:

POWERSHELL / BASH 
# 1. Clone the repository
git clone https://github.com/jigyasaG01/SeeForMe.git
cd SeeForMe

# 2. Create Python 3.13 virtual environment
py -3.13 -m venv venv

# 3. Activate the environment
# Windows PowerShell:
.\venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 4. Install dependencies
pip install -r requirements.txt

# 5. Launch development server
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000

2. REST API Reference

FastAPI endpoints for single-frame perception, health checks, and hardware discovery.

GET /api/status

Returns current pipeline initialization state, active device (CUDA GPU or CPU), and configuration parameters.

JSON RESPONSE 
{
  "status": "online",
  "pipeline_ready": true,
  "device": "NVIDIA GeForce RTX 2050",
  "cuda_available": true,
  "torch_version": "2.14.0",
  "config": {
    "yolo_model": "yolov8n.pt",
    "midas_model": "MiDaS_small",
    "confidence_threshold": 0.40,
    "corridor": [0.30, 0.70]
  }
}
POST /api/process-frame

Processes a single uploaded image file via multipart form-data. Returns bounding boxes, relative distances, directional bearing, debounced speech alerts, and optional base64 depth heatmap.

CURL EXAMPLE 
curl -X POST "http://127.0.0.1:8000/api/process-frame" \
  -F "file=@photo.jpg" \
  -F "confidence=0.40" \
  -F "return_depth_map=true"

3. WebSocket Streaming Protocol

High-throughput full-duplex WebSocket endpoint located at ws://127.0.0.1:8000/ws/stream.

Client Payload: Send Base64-encoded JPEG data URL or binary byte array per camera frame.
Server Payload: Streams immediate JSON responses:

WEBSOCKET JSON EVENT 
{
  "objects": [
    {
      "class_name": "person",
      "confidence": 0.88,
      "box": [120.0, 85.0, 240.0, 390.0],
      "estimated_meters": 1.8,
      "bearing": "slightly left",
      "in_corridor": true
    }
  ],
  "spoken_alerts": [
    "Person, 2 meters, slightly left."
  ],
  "timings": {
    "detection": 22.4,
    "depth": 110.1,

    "total": 133.7,
    "fps": 7.5
  },
  "depth_map": "data:image/jpeg;base64,/9j/4AAQSkZJRg..."
}

4. Configuration Parameters (backend/app/config.py)

Parameter Type Default Description
YOLO_MODEL str yolov8n.pt YOLO weight size: n (nano), s (small), m (medium).
MIDAS_MODEL_TYPE str MiDaS_small Depth model variant (MiDaS_small or DPT_Hybrid).
WALKING_CORRIDOR_LEFT float 0.30 Left boundary of walking path (fraction of frame width).
WALKING_CORRIDOR_RIGHT float 0.70 Right boundary of walking path (fraction of frame width).
DEBOUNCE_COOLDOWN_SEC float 3.0 Suppresses repeat alert chatter for identical hazard bearing.
