System Design

Computer Vision & Fusion Architecture

Explore how SeeForMe harmonizes real-time object detection with relative monocular depth estimation to deliver robust navigation intelligence.

End-to-End Perception Dataflow

Camera Frame (RGB: 640x480) │ ├─► [1] YOLOv8n Object Detector │ ↳ Returns: Bounding Boxes [x1, y1, x2, y2], Class Names, Confidence Scores │ ├─► [2] MiDaS Monocular Depth Estimator │ ↳ Returns: Disparity Map (H x W float32) & Visual Inferno Heatmap │ ├─► [3] Spatial-Depth Sensor Fusion │ ↳ Samples depth in ground-contact bbox region (75th percentile) │ ↳ Distance = Scale / Disparity (meters approx.) │ ↳ Bearing = Horizontal Center Ratio -> ("slightly left", "directly ahead", etc.) │ ├─► [4] Urgency Scoring & Temporal Debounce │ ↳ Walking corridor mask: Priority given to center 40% of walking trajectory │ ↳ Debouncer: Suppresses repeat alerts within 3.0s unless distance decreases by > 0.7m │ └─► [5] Voice Guidance Dispatcher ↳ Generates concise speech strings: "Caution: Person, 2 meters ahead, slightly left." ↳ Broadcast via WebSocket to Web Speech API synthesizer
Algorithmic Innovation

Solving the Depth & Ground-Bleed Challenge

How SeeForMe avoids common pitfalls in monocular depth estimation for pedestrian navigation.

Ground-Contact Cropping

A naive average of depth pixels across an entire bounding box causes major errors because tall pedestrians or vehicles include distant background pixels (walls, road horizons, sky) within their box corners.

Solution: SeeForMe samples the bottom 30% to 90% vertical and 20% to 80% horizontal core where the object contacts the walking surface, taking the 75th percentile disparity value to isolate the true physical obstacle distance.

Relative-to-Metric Calibration

MiDaS outputs an inverse relative depth (disparity $d$). Closer items yield higher disparity values, while distant horizons approach zero.

Z_approx = clamp( Scale / max(1.0, Disparity), 0.5m, 15.0m )

This provides intuitive distance brackets ("under 1 meter", "2 meters", "3 meters", "in the distance") that are immediately understandable through speech.

Urgency Prioritization Formula

Every frame ranks all visible objects with a multi-factor urgency equation:

Score = (Proximity * 1.5) + (InCorridor * 1.2) + (HazardWeight * 2.0)

Vehicles and approaching hazards receive higher weights than static background objects, guaranteeing safety-critical warnings are never drowned out.

Spatial Direction Slicing

Horizontal normalized coordinates ($\hat{x} = \frac{x_{center}}{W}$) are partitioned into 5 natural directional zones:

  • 🔹 < 20%: Far Left
  • 🔹 20% – 38%: Slightly Left
  • 🔹 38% – 62%: Directly Ahead (Walking Corridor)
  • 🔹 62% – 80%: Slightly Right
  • 🔹 > 80%: Far Right
